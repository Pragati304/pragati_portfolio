Run locally

Open index.html in any browser. No install needed.

Deploy on GitHub Pages
Name the repository Pragati304.github.io and keep it public.
Upload these files to the root of the repo.
Go to Settings → Pages, choose Deploy from a branch, select main and / (root), and save.
The site goes live at https://pragati304.github.io within a couple of minutes.
Updating
Photo: replace pragati.jpg with a new file of the same name.
Resume: replace Pragati_Kote_Resume.pdf with a new file of the same name.
Content or colors: edit index.html. The colors are defined once at the top of the file under :root.
